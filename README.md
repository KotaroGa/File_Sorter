
### Smart File Sorter 🗂️

A simple, configurable Python tool to automatically organize your messy folders.

> **Work in Progress** - MVP under development

### 🚀 Current Features (v0.3.0)

#### Core Sorting Engine
- **Smart Categorization**: Automatically categorizes files by extension
- **Conflict Resolution**: Handle duplicates with append_number, skip, or overwrite
- **Folder Structure**: Preserve or flatten folder hierarchies
- **Dry-Run Mode**: Preview changes before actually moving files
- **Statistics**: Get detailed reports of what was moved/skipped

#### Configuration
- JSON-based configuration files
- Customizable categories and file extensions
- Flexible options for different sorting strategies

#### Technical
- Pure Python (no external dependencies)
- Comprehensive logging
- Type hints throughout
- Unit and integration tests
